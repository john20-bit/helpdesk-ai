# Wi-Fi Troubleshooting

## Wi-Fi connected but no internet

Symptoms:
- Device shows connected to Wi-Fi.
- Websites do not load.
- Internet applications cannot connect.

Troubleshooting:
1. Check whether other devices connected to the same Wi-Fi have internet access.
2. Restart the Wi-Fi router.
3. Disconnect and reconnect to the Wi-Fi network.
4. Forget the Wi-Fi network and reconnect using the correct password.
5. Check the device IP address and DNS configuration.
6. Restart the computer.
7. If other devices also have no internet, the issue may be with the router or Internet Service Provider.

## Cannot connect to Wi-Fi

Troubleshooting:
1. Make sure Wi-Fi is enabled.
2. Check whether the network is visible.
3. Restart Wi-Fi on the device.
4. Restart the router.
5. Forget the network and reconnect.
6. Check whether other devices can connect.
