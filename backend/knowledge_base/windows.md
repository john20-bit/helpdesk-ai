# Windows Troubleshooting

## Computer is running slowly

Possible causes:
- Too many background applications
- Low storage
- High memory usage
- Startup applications
- Pending updates

Troubleshooting:
1. Restart the computer.
2. Close unnecessary applications.
3. Check available storage.
4. Check Task Manager for high CPU or memory usage.
5. Disable unnecessary startup applications.
6. Install pending system updates.
7. Scan for malware if suspicious behavior is present.

## Windows application is not responding

Troubleshooting:
1. Wait briefly to determine whether the application recovers.
2. Close the application.
3. Restart the application.
4. Restart the computer.
5. Check for application updates.
6. Reinstall the application if the issue continues.
