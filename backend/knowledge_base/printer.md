# Printer Troubleshooting

## Printer is not printing

Troubleshooting:
1. Check that the printer is powered on.
2. Check USB or network connectivity.
3. Make sure the correct printer is selected.
4. Check for paper and ink or toner.
5. Clear stuck print jobs.
6. Restart the printer.
7. Restart the computer.
8. Check whether the printer appears online.

## Printer is offline

Troubleshooting:
1. Verify the printer is powered on.
2. Check network connectivity.
3. Restart the printer.
4. Restart the computer.
5. Remove and reconnect the printer.
