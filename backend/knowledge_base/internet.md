# Internet Troubleshooting

## No internet connection

Possible causes:
- Router problem
- ISP outage
- DNS failure
- Incorrect IP configuration
- Network adapter issue

Troubleshooting:
1. Check router status lights.
2. Restart the router.
3. Test another device on the same network.
4. Check whether the device has a valid IP address.
5. Test access to a known website.
6. Restart the network adapter.
7. If multiple devices are affected, contact the Internet Service Provider.

## Internet is very slow

Troubleshooting:
1. Check whether other devices are consuming bandwidth.
2. Restart the router.
3. Move closer to the Wi-Fi router.
4. Disconnect unused devices.
5. Test the connection at another time.
6. Contact the ISP if the issue continues.
