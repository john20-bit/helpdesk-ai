# Bluetooth Troubleshooting

## Bluetooth device cannot connect

Troubleshooting:
1. Make sure Bluetooth is enabled.
2. Make sure the device is discoverable.
3. Move the devices closer together.
4. Check whether the Bluetooth device has sufficient battery.
5. Remove the existing pairing.
6. Restart Bluetooth.
7. Restart the computer.
8. Pair the device again.

## Bluetooth device is not detected

Troubleshooting:
1. Confirm Bluetooth is enabled.
2. Put the device into pairing mode.
3. Check whether another device is already connected.
4. Restart the Bluetooth device.
5. Restart the computer.
